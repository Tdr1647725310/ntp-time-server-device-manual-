# 设备网页配置说明书

## 一、操作步骤

### 1. 登录方式

1. 用网线连接设备与电脑网口，查看设备显示的 IP：`192.168.0.123`。
2. 电脑设置同设备 IP 网段，打开浏览器输入设备 IP。
3. 登录账号：`admin`，密码：`admin`。

### 2. 主页功能分区

| 功能 | 说明 |
| --- | --- |
| 实时信息区 | 每秒刷新：GPS 原始解析时间、RTC 当前本地时间、设备以太网 IP 地址 |
| 网络静态 IP 设置 | 可自定义 IP、网关、子网掩码，保存重启生效 |
| 时区选择 | 全球时区下拉可选，默认 UTC+08 北京时间 |
| GPS 同步间隔 | 单位秒，范围 10~300，代表每隔时间校准一次 RTC，推荐 30 秒 |
| 保存重启按钮 | 所有修改点击保存，设备自动重启加载新参数 |
| 安全退出登录 | 清除登录状态，跳转登录页面 |

## 二、时间同步逻辑优先级

1. **最高优先级**：GPS 定位正常 + PPS 脉冲 → 高精度校准 RTC（误差 ＜100ms）  
2. **兜底方案**：无 GPS → 本地晶振独立走时（日误差 ＜2ppm）

## 三、NTP 客户端使用方法（Windows / 设备通用）

### Windows 系统

设置 → 时间和语言 → 附加日期、时间和区域设置 → Internet 时间 → 更改设置，服务器填入本设备静态 IP，立即更新时间。

### 工业设备（PLC / 摄像头 / 记录仪）

NTP 服务器地址填写本机 IP，端口 `128`，同步周期 `60s` 即可。
